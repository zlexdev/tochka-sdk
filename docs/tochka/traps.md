# Ловушки Точка API

Всё, что стоило времени и не написано в документации банка. Каждая проверена — рядом сказано чем.

## Спецификации нет в открытом виде

`enter.tochka.com` редиректит на `developers.tochka.com` — сайт на Docusaurus. Спецификации
по адресу нет: любой путь (`openapi.json`, `swagger.json`, `assets/js/main.*.js`) отдаёт
**один и тот же HTML‑шелл в 22 364 байта со статусом 200** — то есть неверный URL выглядит
как успешный ответ. Старый `enter.tochka.com/uapi/static/openapi.json` → 403.

Как она достаётся на самом деле: плагин openapi‑docs кладёт **каждую операцию в свой
webpack‑чанк**; имя файла собирается из **двух** мап в `runtime~main.js` (`id → name` и
`id → hash`), а сам объект операции лежит в `frontMatter.api` как **zlib + base64**.

Забирается это `python scripts/download_tochka_specs.py` — 167 операций.

## Один продукт ≠ один хост

`cyclops` обслуживается с `api.tochka.com`, `pay-gateway` — с префиксом `uapi/pay/`. Клиент
с единственным базовым URL отправляет **73 из 167** методов не туда, и часть таких запросов
не падает, а отвечает чужой ошибкой. В SDK хост выбирается по `__product__` каждого метода;
закреплено тестами `tests/test_products.py`.

## Тестового сервера нет у всех продуктов

`tochka-api`, `info`, `express-credit` → `sandbox/v2/`; `cyclops` → `pre.tochka.com`;
`medusa` → `stage-uapi.tochka.com`; **`pay-gateway` — нет вовсе**. Молчаливый откат
«песочница → прод» на эквайринге двигал бы настоящие деньги, поэтому SDK бросает
`ConfigurationError`.

## Схемы всегда inline, `$ref` не встречается

Портал разворачивает все ссылки перед публикацией. Любой инструмент, который ориентируется
на `components/schemas` или `$ref` в ответе, тихо ничего не найдёт: у нас на этом трижды
отключились фичи генератора (пагинация, bound‑методы, определение сущностей).

## Конверт ответа — `{Data, Links, Meta}`

Полезные данные всегда внутри `Data`, а не в корне; идентификаторы сущностей тоже там.
`Meta.totalPages` есть даже у непагинируемых ответов.

## Два вида пагинации

`page` + `perPage` на Open Banking и `limit` + `offset` в эквайринге. Универсального
параметра нет; SDK прячет оба за одним курсором.

## `operationId` — FastAPI‑стиль

Банк отдаёт идентификаторы вида
`get_balance_info_open_banking_v1_0_accounts__accountId__balances_get`: имя функции плюс весь
путь плюс метод. Для имён классов их нужно урезать, иначе получается
`GetBalanceInfoOpenBankingV10AccountsAccountIdBalancesGet`.

## Cyclops — JSON‑RPC, а не REST

Один путь на метод (`/v2/jsonrpc/create_deal`), тело `{id, jsonrpc, method, params}`, всё
полезное — в `params`. Ошибки тоже приходят в конверте JSON‑RPC, а не HTTP‑статусом.

## Поля ответов конфликтуют с именами языка

В ответах встречаются поля `client`, `payload`, `url`, `date`, `type`. Свойство или метод
базового класса с таким именем оказывается затенён полем — pydantic предупреждает один раз,
а данные потом недоступны.

## Ошибка не там, где кажется

Конверт ошибки: `{code, id, message, Errors: [{errorCode, message, url}]}`. `code` — это
HTTP‑статус строкой (`"400"`), а настоящая причина в `Errors[0].errorCode`. Ветвиться нужно
по нему.

## Суммы

В JSON приезжают числами (`1234.56`) — для сложения переводите в `Decimal` строкой. В части
методов СБП сумма, наоборот, в **копейках** целым числом: сверяйтесь с описанием поля.
