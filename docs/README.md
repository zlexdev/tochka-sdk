## С чего начать

Пишете интеграцию → [быстрый старт](sdk/quickstart.md), затем
[ловушки](tochka/traps.md): они экономят больше времени, чем справочник.

Выбираете механизм выплат → [выплаты](tochka/payouts.md).

Обновляете SDK под изменения банка → [генератор](../dev/codegen/_MODULE.md).
