# Пагинация

Пагинируемый метод возвращает **курсор**, а не результат: запрос не уходит, пока курсор не
дождались или не начали обходить.

```python
first = await client.get_subscription_list(customer_code="300123456")     # одна страница

async for page in client.get_subscription_list(customer_code="300123456"):
    ...                                                                    # страница за страницей

async for item in client.get_subscription_list(customer_code="300123456").items():
    ...                                                                    # плоско, по элементам
```

Отдельных `*_paginated` методов нет — это тот же метод.

## Размер страницы

```python
cursor = client.paginate(GetSubscriptionList(customer_code="300123456"), page_size=50)
```

## Два стиля под одним курсором

Банк пагинирует по‑разному: `page` + `perPage` в Open Banking и `limit` + `offset` в
эквайринге. Курсор одинаков в обоих случаях; какой стиль у метода, видно по его базовому
классу — `PageMethod` или `OffsetMethod`.

## Где обход останавливается

На первой странице, где список внутри `Data` пуст. Пустая страница наружу не отдаётся.

**Ответ без списка вообще считается терминальным и непустым** — обход прекращается после
него. Догадываться о «пустоте» в незнакомой форме ответа значило бы молча обрезать выдачу.

## Идёт ли счёт страниц с единицы

Да: первый запрос уходит с `page=1`. У `OffsetMethod` первый запрос — `offset=0`.

## Когда пагинация не включилась

Метод, у которого банк объявил параметры страниц, но SDK их не подхватил, — это дефект
генератора, а не особенность API. Смотреть `PAGINATION_STYLES` в
`dev/codegen/engine/build.py`; так уже было: проверка требовала `$ref` у ответа, а Точка
всегда отдаёт схемы inline, и пагинация не включалась ни разу.
